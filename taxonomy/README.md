# taxonomy/

The technique catalogues the pipeline reads; the released ones are symlinks into the data repository's subtree
`data-repo/` (below), the drafts and older catalogues regular files. The taxonomy's history (v0.1-v0.5, the v0.6 working docs and
renderings, the June 2026 design docs, the founding chat and design-brief exports, the unused `technique_papers.yaml`;
kept apart since 2026-10-14), the v0.6 manifest `taxonomy-v0.6.yaml` and the source corpus
`sources/model-corpus/` (the ~1,860 lab and policy sources, their fetch and technique-extraction pipelines, the LFS
text bundle) were removed on 2026-10-27 and are not in this repository (root `README.md`, "Removed, and where it lives").

The data repository thesafetystack/the-safety-stack (taxonomy releases, their JSON Schemas: the shared envelope
`taxonomies/schemas/catalogue-0.schema.json` and one per catalogue, which `stack/catalogue.py` reads; the
validator) is a git subtree at `data-repo/`, added squashed. Update it from the repository root (a clean tree):

```bash
git subtree pull --prefix=data-repo https://github.com/thesafetystack/the-safety-stack.git main --squash
uv run --no-sync pytest tests/test_vendored_taxonomies.py -q     # a released file must not change
```

Changes made here under `data-repo/` go back with `git subtree push --prefix=data-repo <data repo>
<branch>` (or a PR there); edit taxonomies in the data repository, not here.
