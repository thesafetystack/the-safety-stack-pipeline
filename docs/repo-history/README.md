# docs/repo-history/

Context, kept apart from the current docs: material describing the project before this repository's history began,
and superseded records kept for context. Nothing in the current docs depends on it.

| File | What it holds |
|---|---|
| `pre-repo-history.md` | How the pipeline was developed from June to November 2026, in an earlier repository (now archived), and who did the work, including work whose code or data is not in this tree. |
| `decisions-D1-D800.md` | The implementation decisions D0-D800 (2026-10-12 to 2026-11-02), unchanged, with the original header; `docs/DECISIONS.md` continues from D801. |
| `superseded-records.md` | Passages moved out of the current docs: the design's provenance, the full run's estimates and open choices of 2026-10, the URL re-key result on the development stores, resolved future-work items. |

Commit ids cited in `docs/DECISIONS.md` and in data and run records refer to the pre-publication repository; they do
not resolve in this one.
